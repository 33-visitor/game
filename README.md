# 二维弹球 · v0.1

一个没有漏球惩罚的浏览器弹球积分小游戏。名称暂定。

操作底部挡板，把球接到中央高分区；碰撞得分，积分解锁升级。认真操作赚得更快，不操作也能靠墙壁和底边继续得分。每轮 **20 分钟有效运行时间**，结束后展示本轮积分、升级次数和球数。

## 打开游戏

下载或克隆本仓库，**双击 `index.html`**，用现代浏览器打开即可。无需 npm、安装依赖、启动服务器或联网。保持 `index.html`、`style.css`、`game.js` 在同一目录。

## 操作

- 在球场内左右移动鼠标，或按 **A / D、← / →** 控制挡板。
- **空格 / Esc**：暂停或继续；也可点击右上角按钮。
- 升级界面点击一张卡，或按 **1 / 2 / 3** 选择。
- **重新开始**：确认后清空当前分数、球和升级，开始新一轮。确认窗口中按 Esc 可取消。
- 切换标签页或窗口失去焦点会自动暂停，返回后点击继续。
- 触屏可在球场内拖动；首版主要面向桌面鼠标和键盘。

## 碰撞和积分

基础分为 1；上、左、右墙初始 ×2，底边 ×1，挡板两端 ×5、中央 ×10。所有数值都是可调整的首版默认值。

漏过挡板的球碰到底边仍然反弹并得分，没有生命扣除、失败判定或自动接球。挡板中央占总长度的 36%，以珊瑚色显示；击中中央收益最高。碰撞位置改变反弹角度，中央命中也保留最小水平速度，避免原地纯竖直刷分。

每颗球独立移动和计分，球之间不互撞。每次碰撞接触只计一次；同一步撞上墙角的两面墙会分别计分。挡板侧面、下表面和圆角同样是实体碰撞，按两端倍率计分。

## 升级

首次累计 20 分时暂停游戏，随机展示三张互不重复的升级卡。选择后立刻生效，可以重复叠加：

- **再来一颗球**：增加 1 颗有独立初速度的小球。
- **挡板加长**：增加 28 单位，中央区按比例变宽；最大 584，满长后该卡退出候选池。
- **墙壁更值钱**：上、左、右墙倍率一起 +1。
- **中央高倍率**：挡板中央倍率 +5。

升级不花费分数。两次升级间的需求从 20 起，按 `上次需求 × 1.35 向下取整 + 10` 增长；下一门槛等于选择时的累计积分加新需求。这样多球同一步大量得分时不会连续弹出同一门槛，所有已得积分仍保留。

“不操作也能成长”指不用一直接球；**升级时仍需回来选卡**。暂停、选卡、重开确认和切到后台时均不计算本轮时间。因此一轮有效时间固定 20 分钟，现实用时取决于暂停时间。

## 部署 GitHub Pages

1. 将这些文件放到 GitHub 仓库的主分支根目录。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择实际存放文件的分支（通常为 `main`）和 **/ (root)**，点击 **Save**。
5. 等待部署完成，使用 Pages 页面显示的网址进入游戏。之后提交更新会重新部署。

仓库已提供 `.nojekyll`；这是纯静态页面，不需要构建流程。步骤依据 [GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。代码上传与 Pages 开通是不同步骤，上传代码本身不表示游戏网址已经上线。

## 文件与调整

- `index.html`：球场、数据面板、操作和对话框。
- `style.css`：布局、配色、窄屏适配和减少动态效果的偏好。
- `game.js`：集中配置 `CONFIG`、物理与积分核心 `Game`、升级和浏览器交互。
- `tests/game.test.cjs`：Node 内置测试，无第三方依赖；玩游戏不需要 Node。
- `AGENTS.md`、`TASK-v0.1.md`：项目约定和原始首版草案。

调整速度、倍率、升级门槛、挡板或时长时，优先修改 `game.js` 顶部 `CONFIG`；若改变可见规则，同时更新页面文案与本文档。

## 验证

安装 Node.js 后可执行：

```sh
node --check game.js
node --test tests/game.test.cjs
```

测试覆盖墙壁、底边和挡板各面碰撞、重叠不重复计分、挡板边界、多球、升级叠加与候选去重、暂停恢复、重开、BigInt 精度、特效上限和到时结算。

测试还会加速模拟完整 20 分钟，检查球的位置和升级流程。固定种子、指定选卡策略下，固定挡板约 1.59 万分 / 15 次升级，理想自动瞄准中央约 19.89 万分 / 24 次升级。**这些是逻辑模拟，不是真人试玩，不代表实际玩家的成绩或最终平衡。**

本次真实检查详见 `TESTING.md`。

## 当前限制

- 无存档；关闭、刷新页面后本轮进度丢失。
- 20 分钟为有效游戏时间，升级选择和暂停会延长现实用时。
- 数值和成长手感尚需真人试玩调整；大球量性能未承诺适用于所有设备。
- 对浮字数量和生命周期设上限，不限制实际计分，不为特效减少球数。
- 不含砖块、敌人、商店、排行榜、联网或音效素材。
